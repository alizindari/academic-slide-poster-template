The left and right matrices in self-attention

\({\color{#3567A9}\mat Q}=\mat X\mat W_Q\) \({\color{#C45B50}\mat K}=\mat X\mat W_K\) \({\color{#2D7D67}\mat V}=\mat X\mat W_V\)
1 · match + mask
\(\displaystyle \mat S=\frac{{\color{#3567A9}\mat Q}{\color{#C45B50}\mat K}^{\top}}{\sqrt{d_k}}+{\color{#765C99}\mat M_{\mathrm{causal}}}\)
Compare queries with keys; hide future positions.
\(\Longrightarrow\)
2 · normalize
\(\displaystyle {\color{#B04F72}\mat A}=\operatorname{softmax}_{\mathrm{row}}(\mat S)\)
Turn each score row into attention weights.
\(\Longrightarrow\)
3 · retrieve
\(\displaystyle \mat Z={\color{#B04F72}\mat A}{\color{#2D7D67}\mat V}\)
Use those weights to mix the values.
\(\displaystyle \mat Z = \underbrace{ \operatorname{softmax}\!\left( \frac{(\mat X\mat W_Q)(\mat X\mat W_K)^{\top}}{\sqrt{d_k}} +\mat M_{\mathrm{causal}} \right) }_{\color{#B04F72}\text{left matrix }\mat A} \mat X \underbrace{\mat W_V}_{\color{#765C99}\text{right matrix}} \)
\(\mat A\) mixes token rows; \(\mat W_V\) mixes features within each token row.
