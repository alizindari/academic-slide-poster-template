# Visual transformer slides

A fully populated 15-slide teaching template that develops self-attention from
token representations through the complete masked-attention equation.

The content is intentionally included rather than replaced with empty
placeholders. It demonstrates the template's diagram-heavy layouts, coordinated
color system, matrix notation, and progressive teaching narrative.

Open `index.html` through a local web server, or render it from the repository root:

```bash
./shared/slide-system/render-pdf.sh templates/slides-transformer/index.html templates/slides-transformer/slides.pdf
```

See `references.md` for source material. The repository links to third-party
references rather than bundling their PDFs.
The committed `slides.pdf` is the rendered counterpart of `index.html`.
