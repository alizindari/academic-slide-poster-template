# Poster example: DISeL

A completed research-poster example showing the poster system with real equations, figures, experimental results, and a three-column narrative.

The navy, rust, and gold palette, colored section headers, and clean DISeL
diagram match the poster templates. `base.css` holds the original typography
and layout; `style.css` controls the visual refinements. Edit the palette at
the top of `style.css`. All figure assets are included in this folder.

Use `templates/poster-vertical/` or `templates/poster-horizontal/` as the
starting point for a new project. This folder is an example with
project-specific content and should not be treated as a blank template.

Serve the repository root and open `http://localhost:8000/examples/poster-disel/`.
The committed `poster.pdf` is the print-ready rendering of `index.html`.
