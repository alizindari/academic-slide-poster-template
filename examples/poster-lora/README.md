# Poster example: LoRA vs. Full Fine-Tuning

A complete research-poster example connecting excess-risk theory for LoRA and
full fine-tuning with linear-regression and Qwen2.5 experiments. It demonstrates
how the poster system handles theorem statements, dense equations, multi-panel
figures, and a three-column technical narrative.

Use `templates/poster/` as the starting point for a new project. This folder is
a subject-specific example and should not be treated as a blank template.

Serve the repository root and open `http://localhost:8000/examples/poster-lora/`.
The committed `poster.pdf` is the print-ready rendering of `index.html`.
